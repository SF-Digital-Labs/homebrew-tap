# SF Digital Homebrew Tap

```bash
brew install sf-digital-labs/tap/aoraki
```

Formulae here are binary installs pinned to the latest GitHub release of the
corresponding SF Digital tool; `.github/workflows/sync.yml` keeps them
current (daily, or run it manually right after a release).

| Formula | Tool |
|---|---|
| `aoraki` | [Aoraki CLI](https://sf-digital-labs.github.io/aoraki-cli/) — ship code to the Aoraki cloud from your terminal |
